# OpenCode Config in Dotfiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the declarative part of `~/.config/opencode/` into `config/opencode/`, delete APM, and make global plugin uninstall a plain `opencode plugin remove`.

**Architecture:** A new deploy list, `SUBDIR_LIST`, links each tracked file in `config/opencode/` into `~/.config/opencode/` instead of linking the directory, because OpenCode writes runtime state (`service.json`, `plugins/`, `skills/`) into that directory. `opencode.json` is rewritten to V2 shapes so one config file is the source of truth for providers, MCP servers, and package plugins.

**Tech Stack:** bash deploy scripts, OpenCode V2 config JSON, APM removal.

**Spec:** this document (design agreed in session; no separate spec file).

## Global Constraints

- Symlink only these entries into `~/.config/opencode/`: `opencode.json`, `cli.json`, `AGENTS.md`, `themes/`.
- Never track or link: `service.json`, `plugins/`, `skills/`, `commands/`, `agents/`, `.caveman-*`, `.playwright-mcp`, `opencode.json.bak`.
- No secret in any tracked file. Provider key is `{env:NINEROUTER_API_KEY}`, read from `~/.9router/api-key` by `.zshenv`.
- Update both `scripts/initialize.sh` and `scripts/uninitialize.sh` for any new list.
- `bash scripts/test-deploy.sh` must pass after every task.
- Conventional Commits, stage named files only.

## Review Focus

- `$HOME/.config/opencode` missing entirely (fresh machine): `link_contents` must create it and link files. Covered by smoke test.
- `--dry-run` must not create `~/.config/opencode`. Covered by smoke test.
- `uninitialize.sh` must remove only our links and keep a foreign file inside `~/.config/opencode/`. Covered by smoke test.
- A real (non-symlink) `~/.config/opencode/opencode.json` must never be clobbered: the script prints `Backup needed:`. Verified manually in Task 4 before linking.
- Config with a misplaced key degrades silently: `opencode plugin list` and `opencode mcp list` must still show every entry after the rewrite.
